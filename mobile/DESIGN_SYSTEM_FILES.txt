DEPENDENCIES
============

Required:
- expo-font          Font loading
- react-native-svg   SVG blob shapes
- expo-router        Navigation
- expo-splash-screen Splash screen management

Optional:
- react-native-reanimated   (for future animations)
- expo-linear-gradient      (alternative to SVG gradients)


INSTALLATION
============

1. Install dependencies:
   npx expo install expo-font react-native-svg

2. Download fonts (see /mobile/assets/fonts/README.md):
   - Fraunces (display)
   - Plus Jakarta Sans (body, free alternative to Cabinet Grotesk)
   - Inter (UI)
   - Caveat (accent)

3. Place font files in:
   /mobile/assets/fonts/

4. Import and use:
   import { Text, Button, Card } from '@/components/design-system';
